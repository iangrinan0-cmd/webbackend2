# Mente Detective

PWA en español para entrenar observación, deducción, memoria y pensamiento crítico con 1.000 casos generados a partir de escenarios y reglas de razonamiento.

## Publicar en GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)** y guarda.
4. Espera a que termine el despliegue; la URL aparecerá en esa misma pantalla.

## Instalar en Android
Abre la URL publicada en Chrome → menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.

El progreso se guarda en localStorage en el dispositivo. La app no necesita cuentas ni servicios externos.
